# Portfolio Website

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern and beautiful UI/UX design
- 📱 Fully responsive layout
- 🌙 Dark mode support
- ✨ Smooth animations with Framer Motion
- ⚡ Fast and optimized with Next.js
- 🎯 SEO friendly

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

### Personal Information

1. Update your name and title in `components/Hero.tsx`
2. Add your about information in `components/About.tsx`
3. Update skills in `components/Skills.tsx`
4. Add your projects in `components/Projects.tsx`
5. Update contact information and social links in `components/Contact.tsx`
6. Update metadata in `app/layout.tsx`

### Styling

- Colors can be customized in `tailwind.config.js`
- Global styles are in `app/globals.css`

## Build for Production

```bash
npm run build
npm start
```

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations

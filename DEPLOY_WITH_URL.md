# Deploy Using GitHub URL

## You're on the Right Page!

If Vercel is asking for a GitHub URL, that's perfect! Here's what to do:

### Step 1: Enter Your Repository URL

In the input field, paste this URL:
```
https://github.com/mitikmol/portfolio
```

### Step 2: Click "Continue" or "Import"

After entering the URL, click the button to proceed.

### Step 3: Configure (Usually Auto-Detected)

Vercel should automatically detect:
- ✅ Framework: Next.js
- ✅ Build Command: `npm run build`
- ✅ Output Directory: `.next`

**You usually don't need to change anything!**

### Step 4: Click "Deploy"

Click the Deploy button and wait 1-2 minutes!

---

## Alternative: Connect GitHub Account

If you see an option to "Connect GitHub" or "Import from GitHub":
1. Click that button
2. Authorize Vercel
3. Then you'll see a list of your repositories
4. Select "portfolio"
5. Click "Import"

---

## What Happens Next:

1. Vercel clones your repository
2. Installs dependencies (`npm install`)
3. Builds your Next.js app (`npm run build`)
4. Deploys it live
5. Gives you a URL like: `https://portfolio-mitikmol.vercel.app`

That's it! Your portfolio will be live! 🎉

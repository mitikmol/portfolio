# 🚀 Deploy Your Portfolio - Step by Step

## Quick Deploy to Vercel (5 minutes)

### Step 1: Go to Vercel
👉 **https://vercel.com/signup**

### Step 2: Sign Up
- Click **"Continue with GitHub"** button
- Authorize Vercel (click "Authorize vercel")

### Step 3: Import Project
1. Click **"Add New Project"** (big button)
2. Find **"portfolio"** in the list
3. Click **"Import"** next to it

### Step 4: Deploy
1. Vercel auto-detects Next.js (no changes needed!)
2. Click **"Deploy"** button
3. Wait 1-2 minutes ⏳

### Step 5: Done! 🎉
- Your site is live!
- Copy the URL (like: `https://portfolio-mitikmol.vercel.app`)
- Share it with the world!

## Troubleshooting:

**If you don't see "portfolio" repository:**
- Make sure you're logged in with the correct GitHub account
- Refresh the page
- Check: https://github.com/mitikmol/portfolio exists

**If build fails:**
- Check the error message in Vercel
- Usually it's a dependency issue
- Let me know and I'll help fix it!

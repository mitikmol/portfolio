# How to Find "Add New Project" on Vercel

## Option 1: Dashboard Home
1. After signing in, you should be on the **Dashboard**
2. Look for a **big blue/purple button** that says:
   - "Add New..." 
   - "New Project"
   - "+ New Project"
   - Or just a **"+"** icon in the top right

## Option 2: Top Navigation Bar
1. Look at the **top right corner** of the page
2. You might see:
   - A **"+"** button
   - Or **"Add"** dropdown menu
   - Click it and select "Project"

## Option 3: If You See "Import Project"
1. Some versions show **"Import Project"** instead
2. Click that button
3. It does the same thing

## Option 4: Direct Link
Try going directly to:
👉 **https://vercel.com/new**

This should take you straight to the "Import Project" page!

## Option 5: If You See Your Projects List
1. If you see a list of projects (even if empty)
2. Look for a button that says:
   - "Create Project"
   - "Import Project" 
   - Or a card that says "Add New Project"

## What the Page Should Look Like:
- You should see a list of your GitHub repositories
- Each repo has an "Import" button next to it
- Look for "portfolio" in that list
